## 🚀 Featured Projects

### 🏨 [Crystal Horizon Hotel — Hotel Booking Management System](https://github.com/badhanamitroy/Hotel-Booking-Management-System)

> An offline-first hotel management system for a small hotel: rooms, bookings, billing, and POS on a local PC.

| | |
|---|---|
| 🏗️ **Architecture** | PHP 8.5 + MariaDB/MySQL, `public/` as the only web root, services in `src/`, numbered SQL migrations |
| 🔐 **Security** | Argon2id + pepper, RBAC roles & permissions, CSRF on state-changing forms, prepared statements, append-only audit log |
| 🛏️ **Booking integrity** | `room_nights` table with `UNIQUE(room_id, night_date)` to prevent double-booking |
| 💰 **Money handling** | `DECIMAL(12,2)` in the DB and integer-paisa arithmetic in PHP (BDT) |
| 🧾 **Billing design** | Per-stay folio with append-only lines; voids as reversing entries |
| 🧪 **Quality** | Migration runner with checksums, smoke tests, and POS money tests |
| 🚧 **Status** | Foundation phase done; booking, billing, POS, and reports on the roadmap |

`PHP` `MySQL / MariaDB` `RBAC` `Migrations` `POS`

### 🩺 DocBot 2026 — Explainable & Uncertainty-Aware Medical Decision Support

> Undergraduate thesis: preliminary disease prediction from symptoms with transparent, calibrated, and cautious ML.

| | |
|---|---|
| 🧩 **Model** | Soft-voting ensemble: Logistic Regression + SVC (RBF) + LightGBM |
| 🗂️ **Approach** | NLP symptom extraction + hierarchical classification across a clinical disease taxonomy |
| 🔍 **Explainability** | SHAP-based explanations |
| ⚖️ **Reliability** | Probability calibration + uncertainty-aware abstention |
| 💊 **Knowledge Base** | Bangladesh-focused medicines (generics & local brands) with an editable workflow |
| 📈 **Results** | **91.54% accuracy** · **0.9002 Macro F1** |

`Python` `Scikit-learn` `LightGBM` `SHAP` `NLP`
